# Markov Decision Process (MDP) in C++ 

본 프로젝트는 불확실한 환경 속에서 최적의 의사결정을 내리기 위한 수학적 프레임워크인 **마르코프 결정 과정(Markov Decision Process, MDP)**을 C++로 구현한 프로젝트입니다.

단순한 상태 전이를 넘어 보상(Reward) 시스템과 에이전트(Agent)의 행동(Action)을 결합하여, 궁극적으로 누적 보상을 최대화하는 최적의 정책(Optimal Policy)을 찾는 강화학습의 기초 로직을 담고 있습니다.

---

## 핵심 개념 (Core Concepts)

### 1. 마르코프 성질 (Markov Property)
"미래는 오로지 현재에 의해서만 결정된다."
어떤 상태 $S_t$에서 다음 상태 $S_{t+1}$로 전이될 확률은 과거의 모든 과정에 영향을 받지 않고 오직 현재 상태에만 의존합니다. 
* **마르코프한 상태 (O):** 체스 게임 (현재 시점의 보드 사진 한 장으로 다음 수 결정 가능)
* **마르코프하지 않은 상태 (X):** 주행 중인 자동차의 사진 한 장 (현재 속도나 방향, 즉 과거의 맥락을 알 수 없어 다음 상태 예측 불가)

### 2. 마르코프 프로세스 (MP) & 리워드 프로세스 (MRP)
* **MP (Markov Process):** 상태의 집합 $S$와 하나의 상태에서 다른 상태로 넘어갈 전이 확률 행렬 $P$로 이루어진 모델입니다. (예: 아이가 깨어있다가 서서히 잠이 드는 상태 전이 과정)
* **MRP (Markov Reward Process):** MP에 보상 함수 $R$과 할인율 $\gamma$가 추가된 모델입니다. 특정 상태에 도달했을 때의 가치를 기댓값으로 계산할 수 있습니다.

### 3. 마르코프 결정 과정 (MDP)
MRP에 에이전트가 주도적으로 취할 수 있는 **액션의 집합 $A$**가 추가된 최종 모델입니다. 에이전트의 액션에 따라 상태가 변하고 보상이 주어집니다.
* $S$: 상태의 집합 (Set of States)
* $A$: 액션의 집합 (Set of Actions)
* $P$: 전이 확률 행렬 (현재 상태에서 특정 액션을 취했을 때 다음 상태로 전이될 확률)
* $R$: 보상 함수 (해당 상태/액션의 결과로 받는 보상의 기댓값)
* $\gamma$: 할인율 ($0 < \gamma < 1$, 미래의 보상을 현재 가치로 환산하는 파라미터)

## 정책과 최적화 (Policy & Optimization)

에이전트는 주어진 상태에서 장기적인 보상을 최대화하기 위해 **정책(Policy)**을 가집니다. 정책은 결정적(Deterministic)일 수도, 확률적(Stochastic)일 수도 있습니다.

최적의 정책을 찾기 위해 본 프로젝트는 다음의 과정을 거칩니다.

### 벨만 방정식 (Bellman Equation)
각 상태에서 특정 정책을 따를 때 예상되는 보상의 합(기댓값)을 계산하여 상태의 가치(Value)를 구하는 핵심 방정식입니다.

$$V(s) = \max_a \left( R(s,a) + \gamma \sum_{s'} P(s'|s,a) V(s') \right)$$

### 최적 정책 탐색 알고리즘
1. **정책 반복 (Policy Iteration):** 주어진 정책을 평가(가치 계산)하고, 그 가치를 바탕으로 정책을 개선하는 과정을 반복합니다.
2. **가치 반복 (Value Iteration):** 각 상태의 가치 함수를 지속적으로 업데이트하며, 가치 함수가 수렴하면 그에 맞는 최적 정책을 도출합니다.

## C++ 구현 세부 사항 (`MDP.cpp`)

이 프로젝트는 복잡한 의사결정 모델을 게임 AI의 상태 머신(FSM) 고도화 및 절차적 콘텐츠 생성(PCG) 등의 로직에 효율적으로 접목할 수 있도록 설계되었습니다.

* **최적화된 메모리 관리:** 상태 및 전이 확률 테이블 처리 시 C++의 이동 의미론(Move Semantics)을 활용하여 불필요한 깊은 복사(Deep Copy)를 방지하고 메모리 할당 부하를 최소화했습니다.
* **객체지향적 설계:** 상태(State), 행동(Action), 보상(Reward)의 매핑을 구조화하여, 추후 다양한 환경이나 규칙이 추가되더라도 유연하게 대응할 수 있도록 구현되었습니다.
